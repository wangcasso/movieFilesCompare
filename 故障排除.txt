问题1: 批处理文件显示乱码
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

现象:
  '馃幀' 不是内部或外部命令
  '瀹夎' 不是内部或外部命令
  等乱码提示

原因:
  Windows批处理文件的编码问题。
  .bat文件使用UTF-8编码保存，但Windows命令行默认使用GBK编码。

解决方案（3选1）:

✅ 方案A: 使用VBScript启动器（推荐）
   双击运行: 启动程序.vbs
   
✅ 方案B: 使用命令行
   1. 按 Win + R
   2. 输入 cmd，回车
   3. 输入:
      cd D:\fileCompare
      python video_dedup.py

✅ 方案C: 直接运行Python文件
   双击: video_dedup.py

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

问题2: Python未找到
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

现象:
  'python' 不是内部或外部命令

原因:
  Python未安装或未添加到系统PATH

解决方案:

步骤1: 检查Python是否安装
   打开命令提示符（Win+R，输入cmd）
   输入: python --version
   
   如果显示版本号，说明已安装
   如果显示"不是内部命令"，需要安装

步骤2: 安装Python
   1. 访问: https://www.python.org/downloads/
   2. 下载Python 3.6或更高版本
   3. 安装时勾选 "Add Python to PATH"
   4. 完成安装

步骤3: 重新运行程序

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

问题3: 视频时长显示0:00
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

现象:
  所有视频的时长都显示为 0:00

原因:
  ffprobe工具未安装（可选组件）

影响:
  • 名称比较 - 正常工作 ✓
  • 大小比较 - 正常工作 ✓
  • 时长比较 - 无法使用 ✗

解决方案:

选项A: 安装FFmpeg（推荐）
  查看: FFmpeg安装说明.txt

选项B: 不使用时长比较
  只使用名称和大小进行比较

问题5: 扫描速度慢
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

现象:
  扫描大量文件时耗时较长

这是正常现象，因为:
• 需要读取每个文件的元数据
• 如果使用ffprobe获取时长，需要额外时间
• 大文件夹包含数百个文件

优化建议:
• 先用小文件夹测试配置
• 暂时禁用时长比较（如不需要）
• 耐心等待扫描完成

问题6: 找不到重复文件
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

现象:
  扫描完成后显示0组重复

可能原因:
• 相似度设置过高
• 比较维度选择不当

调整建议:

找完全相同的文件:
  → 只勾选"文件大小"，100%

找相似的视频:
  → 名称(70-80%) + 大小(95%)
  → 降低阈值试试
