# 🎬 视频文件去重工具

一个功能强大的Windows桌面应用程序，用于检测和删除多个文件夹中的重复视频文件。

## ✨ 功能特性

### 核心功能
- **多维度比较**: 支持按视频名称、文件大小、视频时长三个维度进行检测
- **灵活的匹配策略**: 
  - 可单独使用某个维度
  - 可组合多个维度（交集判断）
  - 每个维度可独立设置相似度阈值
- **智能名称匹配**: 支持文件名相似度计算（如80%相似即判定为重复）
- **批量扫描**: 可同时扫描多个文件夹
- **可视化界面**: 友好的图形界面，操作简单直观

### 技术特点
- 纯Python开发，无需安装额外依赖
- 支持多种视频格式（MP4, AVI, MKV, MOV, WMV, FLV等）
- 多线程扫描，不阻塞界面
- 配置自动保存
- 结果可导出为文本文件

## 📋 系统要求

- **操作系统**: Windows 7/8/10/11
- **Python版本**: Python 3.6 或更高版本
- **可选**: FFmpeg/ffprobe（用于精确读取视频时长，非必需）

## 🚀 快速开始

### 方法一：直接运行Python脚本（推荐）

1. **确保已安装Python 3.6+**

2. **运行程序**


## 📖 使用说明

### 1. 添加文件夹
- 点击 "➕ 添加文件夹" 按钮
- 选择要扫描的文件夹（可添加多个）
- 可以移除单个文件夹或清空列表

### 2. 配置比较参数

**比较维度**（可多选）:
- ✓ **视频名称**: 比较文件名（不含扩展名）
- ✓ **文件大小**: 比较文件字节大小
- ✓ **视频时长**: 比较视频播放时长

**相似度阈值**:
- **名称相似度**: 0-100%，建议80%
  - 例如: "电影A.mp4" 和 "电影A_副本.mp4" 相似度约80%
- **大小相似度**: 0-100%，建议95%
  - 允许文件大小有微小差异
- **时长相似度**: 0-100%，建议95%
  - 允许视频时长有微小差异

### 3. 开始扫描
- 点击 "🚀 开始扫描" 按钮
- 等待扫描完成（进度条显示状态）
- 结果会显示在下方列表中

### 4. 查看结果
- 结果按组显示，每组包含重复的文件
- 显示文件名、完整路径、大小、时长等信息
- 统计信息显示总扫描数和重复数

### 5. 导出结果
- 点击 "📋 导出结果"
- 选择保存位置和文件格式（txt或csv）
- 报告包含详细的配置信息和重复文件列表

### 6. 保存配置
- 点击 "💾 保存配置" 保存当前设置
- 下次启动时自动加载

## 💡 使用场景示例

### 场景1: 完全相同的文件
**配置**: 仅勾选"文件大小"，相似度100%
**效果**: 找出字节大小完全一致的文件

### 场景2: 同视频不同命名
**配置**: 
- 勾选"视频名称"（相似度70%）
- 勾选"文件大小"（相似度95%）
**效果**: 找出名称相似且大小相近的视频

### 场景3: 同视频不同格式
**配置**: 
- 勾选"视频时长"（相似度95%）
- 不勾选"视频名称"
**效果**: 找出时长相同但可能名称不同的视频

### 场景4: 严格去重
**配置**: 
- 三个维度全部勾选
- 所有相似度设为95%以上
**效果**: 只有三个维度都高度相似才判定为重复

## 🔧 高级配置

配置文件保存在 `config.json`，可手动编辑：

```json
{
  "use_name": true,
  "use_size": true,
  "use_duration": true,
  "name_threshold": 0.8,
  "size_tolerance": 0.95,
  "duration_tolerance": 0.95
}
```

## 📝 注意事项

1. **视频时长读取**: 
   - 程序优先尝试使用ffprobe读取精确时长
   - 如果ffprobe不可用，时长显示为0，仅基于名称和大小比较
   - 建议安装FFmpeg以获得最佳效果

2. **性能提示**:
   - 大量文件扫描可能需要较长时间
   - 建议在后台线程运行时不要关闭程序
   - 可以先用小文件夹测试配置

3. **准确性**:
   - 名称相似度使用模糊匹配算法
   - 大小和时长使用比例计算
   - 建议根据实际需求调整阈值

## 🐛 故障排除

### 问题1: 程序无法运行
**解决**: 确保安装了Python 3.6+，并检查是否有语法错误

### 问题2: 视频时长始终为0
**解决**: 安装FFmpeg并添加到系统PATH
- 下载: https://ffmpeg.org/download.html
- 将ffprobe.exe所在目录添加到PATH环境变量

### 问题3: 扫描速度慢
**解决**: 这是正常现象，特别是文件夹包含大量视频时
- 可以使用ffprobe加速时长读取
- 或暂时禁用时长比较

### 问题4: 误判重复
**解决**: 调高相似度阈值，或减少比较维度
