# 📖 视频去重工具 - 快速开始指南

## 🎯 项目说明

这是一个功能强大的视频文件去重工具，可以帮助你：
- 扫描多个文件夹中的视频文件
- 根据**视频名称**、**文件大小**、**视频时长**三个维度检测重复
- 支持设置相似度阈值（如名称80%相似就算重复）
- 可以单独或组合使用多个判定标准

## 🚀 立即使用

### 方法1: 双击启动（推荐）

直接双击运行：**`启动程序.bat`**

### 方法2: 命令行启动

```bash
cd D:\fileCompare
python video_dedup.py
```

## 💡 使用步骤

### 第一步：添加要比较的文件夹

1. 点击 "➕ 添加文件夹"
2. 选择包含视频的文件夹（可以添加多个）
3. 例如：
   - D:\Movies\Folder_A
   - D:\Movies\Folder_B
   - E:\Backup\Videos

### 第二步：设置比较条件

**场景A：找完全相同的副本**
- ✓ 只勾选"文件大小"
- 相似度设为 100%

**场景B：找同名但大小略有差异的视频**
- ✓ 勾选"视频名称" + "文件大小"
- 名称相似度：80%
- 大小相似度：95%

**场景C：找同一视频的不同版本**
- ✓ 勾选所有三项
- 名称相似度：70%
- 大小相似度：90%
- 时长相似度：95%

**场景D：只根据时长找重复**
- ✓ 只勾选"视频时长"
- 时长相似度：95%

### 第三步：调整相似度滑块

- **名称相似度**：控制文件名有多相似才算重复
  - 100% = 必须完全相同
  - 80% = 允许有小差异（如"电影.mp4"和"电影_副本.mp4"）
  - 50% = 只要有一半相似就算重复

- **大小/时长相似度**：控制允许的误差范围
  - 95% = 允许5%的误差
  - 90% = 允许10%的误差

### 第四步：开始扫描

1. 点击 "🚀 开始扫描"
2. 等待扫描完成（进度条会显示状态）
3. 查看结果列表

### 第五步：处理结果

**查看结果**：
- 结果按组显示
- 每组是一系列重复的文件
- 可以看到每个文件的详细信息

**导出报告**：
- 点击 "📋 导出结果"
- 保存为txt文件
- 可以分享给他人或在Excel中打开

**保存配置**：
- 点击 "💾 保存配置"
- 下次打开时自动记住你的设置

## 📋 实际案例

### 案例1：清理备份文件夹

**问题**：有多个备份文件夹，不确定哪些视频是重复的

**解决方案**：
1. 添加所有备份文件夹
2. 勾选：名称(80%) + 大小(95%) + 时长(95%)
3. 扫描并查看结果
4. 删除不需要的副本

### 案例2：整理下载的电影

**问题**：从不同地方下载的电影，文件名可能略有不同

**解决方案**：
1. 添加下载文件夹
2. 勾选：名称(70%) + 时长(95%)
3. 降低名称相似度阈值到70%
4. 找出可能是同一部电影的文件

### 案例3：找出相同大小的文件

**问题**：怀疑有些文件是完全相同的

**解决方案**：
1. 添加文件夹
2. 只勾选"文件大小"，100%
3. 快速找出字节级相同的文件

## ⚙️ 常见问题

### Q1: 为什么视频时长显示0:00？

**A**: 这表示程序无法读取视频时长。解决方法：
1. 安装FFmpeg（见 `FFmpeg安装说明.txt`）
2. 或者：只使用名称和大小进行比较

### Q2: 扫描很慢怎么办？

**A**: 正常现象，特别是：
- 文件夹中视频很多
- 视频文件很大
- 启用了时长比较

建议：先用小文件夹测试配置

### Q3: 如何判断是否误判？

**A**: 查看导出的报告，仔细对比每组文件：
- 如果名称差异很大但被判为重复 → 调高名称相似度
- 如果大小差很多但被判为重复 → 调高大小相似度

### Q4: 可以生成exe文件吗？

**A**: 可以！双击运行 `打包成EXE.bat`，会在dist目录生成独立的exe文件

## 🔍 技术指标

- **支持格式**：MP4, AVI, MKV, MOV, WMV, FLV, WebM, M4V, MPG, MPEG, 3GP, RMVB, RM
- **名称算法**：Python difflib SequenceMatcher
- **大小精度**：字节级精确
- **时长精度**：秒级（需要ffprobe）
- **扫描速度**：取决于文件数量和大小
