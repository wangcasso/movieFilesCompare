======================================
💡 主要功能
======================================

✓ 扫描多个文件夹的视频文件
✓ 支持MP4/AVI/MKV等主流格式
✓ 三维度比较:
   - 视频名称（可设相似度，如80%）
   - 文件大小（精确到字节）
   - 视频时长（秒级精度）
✓ 灵活组合:
   - 可单独使用某个维度
   - 可多维度交集判断
✓ 智能检测:
   - 模糊名称匹配
   - 容差范围可调
✓ 结果导出:
   - 生成详细报告
   - 支持TXT/CSV格式

======================================
⚙️ 系统要求
======================================

必需:
  • Windows 7/8/10/11
  • Python 3.6 或更高版本

可选（推荐）:
  • FFmpeg/ffprobe（用于读取视频时长）
    下载地址: https://ffmpeg.org/download.html

======================================
📖 使用场景示例
======================================

场景1: 清理重复备份
  → 添加多个备份文件夹
  → 名称(80%) + 大小(95%) + 时长(95%)
  → 扫描找出重复

场景2: 整理下载的电影
  → 添加下载文件夹
  → 名称(70%) + 时长(95%)
  → 找出同电影不同版本

场景3: 找完全相同的文件
  → 只勾选"文件大小"
  → 相似度100%
  → 快速定位字节级副本

======================================
🔧 技术架构
======================================

编程语言: Python 3
GUI框架: tkinter（标准库）
核心算法: 
  - difflib.SequenceMatcher（名称相似度）
  - 比例计算（大小/时长相似度）
多线程: 后台扫描，不阻塞界面
配置管理: JSON格式自动保存
